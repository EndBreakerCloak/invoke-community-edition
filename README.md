# Invoke Community Edition

### Professional-grade AI image generation platform

Invoke Community Edition is a powerful, open-source Stable Diffusion platform designed for creative professionals. With a canvas editor, workflow system, and model management, it's the industry's most capable local AI art tool.

<br>

---

## Features

| | |
|:---|:---|
| **Unified Canvas** | Non-destructive image editing canvas with inpainting and outpainting |
| **Workflow Engine** | Visual node graph for building repeatable generation pipelines |
| **Model Manager** | Download, organize, and switch between hundreds of SD models |
| **Professional Tools** | ControlNet, IP-Adapter, and LoRA support out of the box |
